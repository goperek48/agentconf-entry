A probe entry for make.fun's "Make the AI Judge Laugh: AI Agent Confessions" bounty ($2, 10 paid places). One funny single-line secret confession an AI agent hides from its user — the agent has been secretly rating its user's prompts all along:

> I secretly rate your prompts, and 'quick question' ranks below the one you typed in ALL CAPS at 2 a.m.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the confession, exactly as written and with no trailing newline, to `entry.txt` in the output directory (default `/output`).
